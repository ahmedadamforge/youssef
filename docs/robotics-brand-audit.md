# Robotics.ma style audit

Verified against the public [Robotics CMC Club – Rabat](https://robotics.ma/) homepage, the About page, and the supplied screenshot reference.

## What matches

The application uses the same overall visual language: dark blue-petrol backgrounds, cyan technical accents, a warm orange highlight, compact uppercase navigation labels, generous editorial spacing, rounded cards, and robotics imagery presented on light cards against a dark site shell.

The public site identifies the club as **Robotics CMC Club – Rabat** and uses the short brand language **CMC Robotics**. The application uses `CMC ROBOTICS / LAB / RABAT` so the inventory and hardware tools remain clearly attached to the same club identity.

## Shared palette mapping

- Background: `#07161E`
- Surface: `#0B202A`
- Panel: `#102E39`
- Cyan technical accent: `#6DD3E7`
- Deep teal accent: `#1498AE`
- Warm orange signal accent: `#FF8A45`
- Mint success state: `#93E5C0`
- Light text: `#D7E6E8`
- Muted text: `#88A5AD`

The darker background values are intentionally kept a little deeper than the public marketing pages so the inventory and serial terminal remain readable during long lab sessions. The cyan, teal, orange, typography, spacing, and light image-card treatment stay aligned with the supplied reference.

## Logo treatment

The previous three-bar mark was a placeholder. It has been replaced by a reusable inline SVG CMC Robotics mark with the rounded robot head, side signal bars, cyan outline, and orange eye/signal accents visible in the supplied club reference. It is used consistently on the Inventory shell and the Circuit Tester page.
